작성일: 2026-10-22 · 버전: 1.0 · 대상: NA2-cabling React 전환

## 목적과 승인 범위

실기 준비생이 커넥터 방향을 이해하고 T568A/B 배열을 재현하며 양 끝 결선 관계를 판단하도록 돕는다. 기존 앱에서 정답이 노출되는 선택지 배열, 수동 진행 중 문항 불일치, 연속 제출 중복 채점, 잘못된 누적·요일 통계를 수정한다.

사용자가 승인한 범위는 PRD 작성, 원본 보존, React 전환, 필기 앱 NA2-com과 디자인 통일, 학습 내용과 채점·통계 오류 수정, 로컬 검증이다. 공개 배포는 별도 단계로 남긴다.

원본 기준은 Git 커밋 `423c7291d09e07ac9c9a48c2a1f743d9fef3e776`이다. 프로젝트 옆의 `NA2-cabling_원본_423c729_20261022.zip`을 별도로 보존하며, 전달받은 SHA-256은 `AE4686D9967E9F0E769D10557C318980DB93C285AE5BB067A311F6FE22A3519E`이다. React 전환은 작업 사본에서 수행하고 보존용 원본 ZIP과 필기 앱 소스는 수정 대상에서 제외한다.

## 화면과 사용자 흐름

| 화면 | 필수 기능 | 다음 행동 |
|---|---|---|
| 대시보드 | 실제 응답 수·정답률·학습 일수, 이어 하기 | 개념 학습 또는 훈련 시작 |
| 개념 학습 | A/B 배열, 양 끝 도해, 통신 속도·포트 조건, 출처 | 연습 시작 |
| 케이블링 훈련 | 핀·색상, 배열 완성, 유형 판별, 혼합 훈련 | 제출 → 다음 문제 → 회차 결과. 해설 공개 시점은 모드별로 구분 |
| 오답 복습 | 문항별 최신 응답이 오답인 문항 목록 | 해당 문항 재시도 |
| 제작 연습 | 10분 타이머, 수동 점검표, 확인 결과 | 제작 결과 자가 기록 |
| 학습 기록 | 실제 제출 이력, 유형별 집계, 최근 7일 기록 | 기록 확인 후 학습 계속 |
| 자료·설정 | 원문 출처, 진행 설정, 백업·복원 | 자료 확인 또는 기록 관리 |

한 회차는 혼합 10문제, 핀·색상 8문제, 배열 완성 2문제, 유형 판별 4문제 중 선택한다. 핀·색상은 16개 템플릿 중 8개를 사용한다. 오답 복습은 현재 오답 전체 또는 선택한 한 문항을 제공한다. 문항 순서와 전선 선택지를 섞는다. 배열 완성에서 같은 전선을 두 번 사용할 수 없다. 이미 고른 전선을 제거하거나 다시 배열할 수 있어야 한다.

연습과 오답 복습에서는 힌트와 참고 배열을 제공할 수 있고, 제출 직후 정오·정답·해설과 잘못 배치한 핀을 보여 준다. 평가는 힌트를 제공하지 않으며 진행 중에는 제출 후에도 정오·정답·해설·오류 핀 표시를 숨긴다. 평가 회차를 마친 결과 화면에서 응답별 정오와 해설을 공개한다. 진행 평가의 제출 기록은 화면 통계·오답 목록·최근 응답에서도 제외한다. 해당 평가를 새 훈련으로 대체하면 이미 제출한 기록을 유지하고 통계·오답 목록·최근 응답에 반영한다. 모든 모드에서 제출한 답안은 잠그고 수동 `다음 문제`를 기본 동작으로 사용한다. 자동 진행을 선택해도 표시 문항과 상태가 함께 전환되어야 한다.

## 통계와 기록 보존

기록의 원천은 유효한 제출 이벤트이다. 이벤트에는 식별자, 회차, 문항, 유형, 학습 모드, 실제 답안, 정오, 제출 시각을 저장한다. 카운터를 여러 곳에서 누적하지 않고 이벤트로 통계를 계산한다.

진행 중인 평가의 `sessionId`에 속한 이벤트도 원본 상태와 백업에는 그대로 보존한다. 화면에 표시하는 통계·오답 목록·최근 응답에서만 그 회차를 제외하며 사이드바 오답 수에도 같은 기준을 적용한다. 회차를 종료하면 제외를 해제한다. 평가 도중 새 훈련을 시작해 회차를 대체한 경우에도 기존 제출 이벤트를 삭제하지 않고 화면 집계에 반영한다. 아래 계산 기준은 이 화면 표시 범위를 적용한 이벤트를 대상으로 한다.

| 항목 | 계산 기준 |
|---|---|
| 전체 정답률 | 정답 이벤트 수 ÷ 전체 유효 이벤트 수 |
| 문항별 첫 응답 정답률 | 모든 모드에서 문항별 최초 제출만 집계하는 보조 지표 |
| 평가 전체 정답률 | 평가 모드의 모든 유효 제출만 집계 |
| 평가 첫 시도 정답률 | 평가 모드에서 문항별 최초 제출만 집계. 연습·복습을 제외 |
| 유형별 기록 | 핀·색상 / 배열 완성 / 유형 판별의 실제 이벤트 집계 |
| 학습 일수 | 제출 기록이 있는 로컬 날짜의 수 |
| 최근 7일 | 오늘 포함 연속 7개 로컬 달력 날짜에 해당하는 제출만 집계. 기록 없는 날은 0건 |
| 미학습 상태 | 정답률은 계산 불가로 표시하고 가상 수치·예시 막대를 만들지 않음 |

통계의 기준 시각은 30초마다 갱신하고 브라우저 창이 다시 포커스를 받을 때도 갱신한다. 자정을 넘기거나 다음 날 창으로 돌아왔을 때 오늘의 집계와 최근 7일 날짜가 새 로컬 날짜를 반영해야 한다.

버전이 있는 새 저장 형식을 사용한다. 기존 `cabling-trainer-progress` 원문은 유지하고 이전 집계 기록으로 정확한 제출 이력을 추정하거나 새 통계에 합산하지 않는다. 이전 기록이 있으면 별도 보존 상태를 안내한다.

손상된 JSON, 지원하지 않는 미래 버전, 중복 이벤트, 잘못된 문항·답안·날짜가 있는 백업은 거부한다. 읽기 실패나 저장 용량 부족이 앱 전체를 중단시키지 않아야 하며, 사용자에게 저장되지 않았음을 알린다. 정상 원본 기록을 자동 덮어쓰지 않도록 보호한다. 백업은 로컬 JSON으로 내보내고 복원 전 검증한다. 자동 저장은 UTF-8 5 MiB 기준이며, 용량 초과 상태를 복구할 수 있도록 가져오기 검사는 64 MiB까지 허용한다. 저장 한도를 넘으면 저장 실패를 안내하고 화면의 기록을 다시 내보낼 수 있어야 한다.

다른 탭에서 같은 앱의 저장 기록이 변경되면 현재 탭의 저장을 중단한다. 현재 탭의 내용을 백업한 뒤 새로고침하여 저장된 기록을 다시 읽도록 안내한다. 오래된 탭 상태가 다른 탭의 최신 기록을 자동 덮어쓰지 않아야 한다.

## 시리즈 디자인과 접근성

NA2-com의 시각 기준을 사용하며 세부 토큰은 [DESIGN.md](../DESIGN.md)에서 관리한다. 기본 배경 `#f3f5f2`, 흰색 카드, 본문 `#192d33`, 주요 색상 `#087a61`, 짙은 탐색 영역 `#103b37`, 강조색 `#a8e5c8`, 경계선 `#dce4df`를 사용한다. 글꼴은 Trebuchet MS·맑은 고딕·시스템 sans-serif 순서이며 외부 폰트 다운로드 없이 동작한다.

데스크톱은 238px 사이드바와 카드 중심 구성, 휴대전화는 폭 360px부터 가로 넘침 없이 제공한다. 터치 버튼은 높이 44px 이상, 키보드 포커스는 명확히 표시한다. 8개 핀 번호와 줄무늬를 유지하고 전체 색상명은 범례·접근성 이름으로 보완한다. 동작 감소 설정을 존중한다.

## 구현과 검증 기준

React + Vite를 사용한다. 학습 콘텐츠, 도해·UI, 순수 채점 모델, 기록 저장을 분리한다. GitHub Pages 기본 경로는 `/NA2-cabling/`을 유지하며 하위 경로에서 자산이 정상 로드되어야 한다.

| 내용 | 원문 근거로 A/B 16핀·4개 조합·송수신 조건을 검토 |
| 독립 모델 회귀검사 | 정답 배열을 테스트 안에 독립 정의하여 채점·중복 제출·수동 진행·종료·복원·통계·저장 오류 검증 |
| 빌드 | 생산용 빌드 성공, 저장소 기본 경로 확인 |

테스트 통과는 웹앱 기능과 기록 계산의 검증이다. 실제 케이블 압착 품질, 도통, 링크 성능, 시험 합격 여부, 실제 휴대전화 기종별 동작은 별도 증거 없이 검증 완료로 보고하지 않는다.
