# 케이블링 트레이너

네트워크관리사 실기 시험의 케이블링 파트를 연습할 수 있도록 만든 단일 페이지 웹앱입니다.

## 실행 방법

바로 열기: https://sumilee-phd.github.io/NA2-cabling/ (휴대폰에서도 동작)

1. 또는 `index.html` 파일을 더블클릭하거나 브라우저에서 엽니다.
2. 하단 탭으로 `학습`, `유형 판별`, `순서`, `통계`, `설정` 화면을 이동합니다.

## 주요 기능

- T568A / T568B 표준 배열 학습
- Direct / Cross 판별 퀴즈
- 색상 순서 맞추기 게임
- 브라우저 `localStorage` 기반 학습 통계 저장
- 학습 목표와 자동 진행 옵션 저장

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 모바일 앱 스타일 UI
- `app.js`: 학습 데이터와 인터랙션 로직
- `manifest.json`: 앱 설치형 메타데이터
